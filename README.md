# 🌍 Международная диверсификация портфеля

Интерактивный Streamlit-дашборд для портфельного анализа мировых индексов.  
Данные загружаются в реальном времени через Yahoo Finance.

---

## Быстрый старт

```bash
pip install -r requirements.txt
streamlit run portfolio_dashboard.py
```

Откроется браузер на http://localhost:8501

## Боковая панель

- **Выбор индексов** — для основных вкладок (динамика, корреляция, портфель)
- **Период анализа** — 3–15 лет
- **DXY** — включить/выключить индекс доллара
- **Метод взвешивания** — равные веса / обратные корреляционные / макс. Sharpe (SLSQP)
- **Безрисковая ставка** — для расчёта Sharpe и Jensen's Alpha

## Модели и методы

**Портфельная оптимизация**
- Mean-variance (Markowitz): аналитическое решение `w* = Σ⁻¹·(μ−rf)`
- Efficient Frontier: 400 точек через SLSQP с ограничением на целевую доходность
- Min Variance: SLSQP без ограничения на доходность

**Риск-метрики**
- VaR / CVaR (исторический метод, уровень доверия 90–99%)
- Maximum Drawdown, Calmar Ratio
- Rolling Beta и Jensen's Alpha к выбранному бенчмарку

**Стохастические модели**
- GBM (Geometric Brownian Motion) — Монте-Карло, до 5 000 траекторий
- GARCH(1,1) — прогноз волатильности, параметры ω / α / β / персистентность
- Heston — стохастическая волатильность, Euler-Maruyama дискретизация, ρ / κ / θ / ξ

**Оптимальный портфель**
- Перебор всех C(n,2)+C(n,3)+C(n,4) комбинаций из всех 19 индексов
- Аналитическое решение касательного портфеля (`np.linalg.solve`) — < 1 сек
- Ручная настройка весов с live-пересчётом всех метрик
